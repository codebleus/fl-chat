Публичный API виджета

Виджет предоставляет публичный API в объекте window.FLCChatbot. Внешний код может вызывать эти методы напрямую.

Доступ к экземпляру
window.FLCChatbot
Методы управления виджетом
window.FLCChatbot.open()
window.FLCChatbot.close()
window.FLCChatbot.toggle()
window.FLCChatbot.lock()
window.FLCChatbot.unlock()
window.FLCChatbot.clear()
window.FLCChatbot.reset()
window.FLCChatbot.getState()
Методы добавления сообщений 
window.FLCChatbot.addBotMessage("Текст сообщения")
window.FLCChatbot.addUserMessage("Текст сообщения")

window.FLCChatbot.addMessage({
  role: "bot",
  blocks: [
    { type: "text", text: "Выберите вариант:" },
    {
      type: "options",
      options: [
        { label: "Вариант 1", value: "v1" },
        { label: "Вариант 2", value: "v2" }
      ]
    }
  ]
})
Методы запроса / ответа
const requestId = window.FLCChatbot.send("Текст сообщения")

window.FLCChatbot.resolve(requestId, {
  text: "Ответ бота"
})

window.FLCChatbot.reject(requestId, "Текст ошибки")

Метод send() добавляет сообщение пользователя, переводит чат в pending и возвращает requestId. Позже по этому id можно вызвать resolve() или reject().

Методы pending
window.FLCChatbot.showPending()
window.FLCChatbot.hidePending()
Transport-режим
window.FLCChatbot.setTransport(async ({ text, requestId, meta }) => {
  return {
    text: "Ответ на: " + text
  }
})

Transport нужен, если внешний код хочет централизованно обрабатывать send() и автоматически возвращать ответ.

Базовые сценарии использования
1. Просто открыть или закрыть виджет 
window.FLCChatbot.open()
window.FLCChatbot.close()
2. Просто показать сообщение от бота 
window.FLCChatbot.addBotMessage("Здравствуйте! Чем могу помочь?")
3. Ручной цикл запроса
const requestId = window.FLCChatbot.send("Физическое лицо")

window.FLCChatbot.resolve(requestId, {
  text: "Уточните, пожалуйста, страну отправления."
})
4. Ручной цикл с ошибкой
const requestId = window.FLCChatbot.send("Физическое лицо")

window.FLCChatbot.reject(requestId, "Сервис временно недоступен")
5. Ответ с вариантами выбора 
const requestId = window.FLCChatbot.send("Хочу оформить перевозку")

window.FLCChatbot.resolve(requestId, {
  text: "Выберите тип перевозки:",
  optionsText: "Доступные варианты:",
  options: [
    { label: "Авто", value: "auto" },
    { label: "Авиа", value: "air" },
    { label: "Море", value: "sea" }
  ]
})
События виджета

Виджет генерирует DOM-события на корневом элементе .chatbot. Их можно использовать для аналитики, логирования и внешней интеграции.

Подписка на события
const root = document.querySelector(".chatbot")

root.addEventListener("chatbot:open", (event) => {
  console.log("open", event.detail.state)
})

root.addEventListener("chatbot:close", (event) => {
  console.log("close", event.detail.state)
})

root.addEventListener("chatbot:outgoing", (event) => {
  console.log("outgoing", event.detail)
})

root.addEventListener("chatbot:resolved", (event) => {
  console.log("resolved", event.detail)
})

root.addEventListener("chatbot:rejected", (event) => {
  console.log("rejected", event.detail)
})

root.addEventListener("chatbot:statechange", (event) => {
  console.log("statechange", event.detail.next)
})
Альтернативная подписка через API 
window.FLCChatbot.on("open", (event) => {
  console.log(event.detail.state)
})

window.FLCChatbot.on("close", (event) => {
  console.log(event.detail.state)
})
Что не является публичным API

Эти методы относятся к внутренней реализации виджета и не должны использоваться внешним кодом. 

renderState()
buildWrap()
buildBlock()
normalizeMessage()
normalizeBlock()
createTextBubble()
createListBubble()
createLoaderBubble()
createOptions()

Например, renderState() — это внутренняя синхронизация state, class и aria-атрибутов. Это не часть контракта интеграции.

Как использовать вместе с сервером

Сервер не вызывает window.FLCChatbot напрямую. Обычно клиентский код получает ответ сервера и затем вызывает методы виджета.

Пример ручной интеграции
const requestId = window.FLCChatbot.send("Физическое лицо")

fetch("/api/chat", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    message: "Физическое лицо",
    requestId
  })
})
  .then((response) => response.json())
  .then((data) => {
    window.FLCChatbot.resolve(requestId, data)
  })
  .catch((error) => {
    window.FLCChatbot.reject(requestId, error.message)
  })
Пример через setTransport
window.FLCChatbot.setTransport(async ({ text, requestId, meta }) => {
  const response = await fetch("/api/chat", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      message: text,
      requestId,
      meta
    })
  })

  if (!response.ok) {
    throw new Error("HTTP " + response.status)
  }

  return await response.json()
})
Управление виджетом

Быстрые действия для проверки открытия, очистки, pending-состояния и сброса.

Ручное добавление сообщений

Используется для проверки отображения сообщений без backend.

Кнопка send() запускает обычный цикл отправки: user message → pending → ожидание resolve/reject.

Тест опций

Формат опций: одна строка = одна опция. Можно писать Текст или Текст|value.

Resolve / reject активного запроса

Здесь можно вручную завершить текущий активный запрос, если transport не подключён или нужен быстрый тест ответа.

Transport

Через fetch transport фронт отправляет запрос на backend endpoint. Mock transport нужен для локальной проверки без сервера.
